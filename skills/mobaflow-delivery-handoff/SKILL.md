# MOBAflow delivery handoff

Use the existing Project Manager assignment and queue reference. Name the sender, exactly one recipient, the current owner, the phase, the scope, and the requested next action. Check applicable stops, protected worktrees, and practical acceptance requirements.

Bind the handoff to the PR head and base, artifact version, or deployment. Include the observation time and time zone. Link existing evidence and distinguish direct observation, owner report, and unknowns.

Track delivery, acceptance, execution end, writer release, CI, review, integration, and practical acceptance separately. If the comparison changes, identify which checks need fresh evidence. Preserve the current writer until the transfer is accepted and any required release is evidenced. Route unclear ownership or sequencing to the Project Manager in the existing queue.

Return assignment, phase, sender, recipient, version, evidence, confirmed states, and next action. If the recipient cannot proceed, name the concrete missing item.
